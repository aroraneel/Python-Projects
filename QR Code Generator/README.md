# QR Code Generator

A simple Python application that generates QR codes from text or website URLs.

## Features

- Generate QR codes from any text
- Generate QR codes from website URLs
- Save the QR code as a PNG image
- Simple command-line interface

## Technologies Used

- Python 3
- qrcode Library
- Pillow

## Installation

Install the required package:

```bash
pip install -r requirements.txt
```

## Run

```bash
python QR.py
```

## Example

Input:

```text
https://github.com/aroraneel
```

Output:

```text
QR Code saved as qrcode.png
```

The generated QR code will be saved in the project folder.
